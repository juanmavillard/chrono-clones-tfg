# Academic reference and asset credits

## Academic reference

Juan María Villard Bardón (2024). *Diseño e implementación de mecánicas de videojuegos basadas en la dimensión temporal*. Bachelor's Final Project, Universidad Carlos III de Madrid. Supervisor: Álvaro Montero Montes.

[Read the original thesis (Spanish PDF)](chrono-clones-tfg.pdf). Chapter 4 covers puzzle design, chapter 6 covers the playtest, and Appendix A contains the code listings.
